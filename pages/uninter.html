Análise de Dados e Machine Learning com Python

Duração: 3 meses
Módulos: 6
Resumo do Curso: Este curso oferece uma introdução abrangente à análise de dados e machine learning utilizando Python. Os alunos aprenderão a manipular, analisar e visualizar dados,além de desenvolver e implementar modelos de machine learning para resolver problemas reais.

Módulo 1: Fundamentos de Python para Ciência de Dados
Módulo 2: Manipulação e Limpeza de Dados
Módulo 3: Visualização de Dados
Módulo 4: Estatística e Probabilidade
Módulo 5: Introdução ao Machine Learning
Módulo 6: Projetos Práticos e Implementação
